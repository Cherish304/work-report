# 首发验证范围

本地 macOS 验证包含：Python 3.9、Bash 安装器语法和隔离目录安装、安装后两份 Skill 入口、DWS 原生 CLI 的中文 UTF-8 stdin dry-run，以及全部离线单元测试。测试数据均为合成内容，没有提交真实钉钉日志，也没有替换用户现有 Skill 或修改现有安排。

覆盖时间窗口、迟到执行截止、指定范围、字段契约、配置校验、确认计时重置、取消不可恢复、哈希变更、并发锁、重复提交保护、超时未知状态、恢复备份、安装回滚、Windows 可执行文件查找和含空格路径。

仓库包含 macOS / Windows、Python 3.9 / 3.12 的 CI 矩阵。CI 配置不是已通过证据，必须以 GitHub 实际运行结果为准；它也不验证真实 DWS 授权、组织模板或端到端发送。

正式启用时仍需由每位用户完成：登录、模板读取、来源权限、仅预览、取消/修改、确认心跳以及一次明确授权的真实提交与回读。Windows 还需要原生 PowerShell、中文编码与用户 ACL 真机验收。
