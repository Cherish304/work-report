# Daily Report

先完整阅读[共用工作流](../../runtime/workflow.md)，遵守来源、平台命令、隐私、确认、去重与未知提交结果处理要求。

辅助入口为本目录 `scripts/report.py`；macOS 使用 python3，Windows 使用实际安装的 Python 启动器。路径按当前安装位置定位，不引用作者机器绝对路径。

字段顺序为：

1. 今日完成工作：按事项归并并编号，写可核实成果和影响。
2. 未完成工作：明确进行中事项、后续动作与未完成原因；没有则“暂无明确未完成事项”。
3. 需协调工作：明确阻塞、依赖或待决策事项；没有则“暂无”。

window 自动使用日报类型。手动为当天零点到调用时刻；定时加 --scheduled，按配置的当日截止时间，不扩展到迟到执行时间。用户起止范围优先。正文不重复日期标题，归属由钉钉登录态及模板确定。

数据只允许同期 rollout summaries、Codex 已完成回合及钉钉工作文本；不读取 Git、原始会话或媒体附件。完成项必须有完成证据，不把他人消息单方面归为本人完成。

先在当前任务预览三字段与来源覆盖，用户仅要求预览时绝不创建提交状态或心跳。后续“提交/取消/修改”及确认心跳均按共用工作流处理，自动提交默认关闭。
