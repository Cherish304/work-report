# Weekly Report

先完整阅读[共用工作流](../../runtime/workflow.md)，遵守来源、平台命令、隐私、确认、去重与未知提交结果处理要求。

辅助入口为本目录 `scripts/report.py`，自动选择周报类型；命令启动器与路径按当前平台和安装位置解析。

字段顺序为：

1. 本周完成工作：归并并编号，优先写可核实结果、价值，再补关键技术信息。
2. 本周工作总结：2–5 条可核实的进展、质量、风险或复盘。
3. 下周工作计划：仅提取明确待办、后续和计划；没有则“暂无明确计划，请在提交前补充”。
4. 需协调与帮助：明确阻塞、依赖和待决策事项；没有则“暂无”。

手动工作日从本周一零点到当前时刻；周末汇总最近完整周一到周五。定时必须使用 --scheduled，并按配置 previous_workweek/current_workweek 解析。默认每周一汇总上一完整工作周。显式起止范围优先。正文不重复日期标题。

数据只允许同期 rollout summaries、Codex 已完成回合与钉钉日报，不读取 Git、原始会话或非必要聊天。来源冲突在预览标注“待确认”，不猜测。不能用周报创建日替代正文统计期判断重复提交。

先预览四字段与覆盖统计，用户仅要求预览时不创建待确认状态/心跳。自动提交默认关闭；提交、取消、修改与确认心跳按共用工作流执行。
